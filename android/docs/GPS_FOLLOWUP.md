# トンネル・地下道・陸橋に向けた追加機能案

以下は未実装の開発候補です。トンネル・地下道・陸橋等によるGPS欠測を想定しています。

| 優先度 | 機能 | 内容・制約 |
| --- | --- | --- |
| 高 | センサ原記録と再計算 | 20〜50Hz程度の加速度・ジャイロ・姿勢、気圧、精度、単調時刻、GPS原測位を保存。欠測と採用/除外理由を残す。容量を制限し、補正で原記録を上書きしない |
| 高 | 停車時の誤差補正 | 停車を裏付けられた区間で速度・バイアスを補正。小さい加速度や小さいBMS電流だけで停止としない。減速経過・GPS・取得できれば車速を照合し、等速の惰性走行との誤認を防ぐ |
| 高 | 磁気に依存しない姿勢推定 | GAME_ROTATION_VECTORとジャイロを候補にする。磁北が得られないため、良好な走行GPSで向きを合わせ、時間とともに増える方位誤差を管理する |
| 高 | GPS復帰の連続照合 | 出口直後の単発測位で経路を確定せず、複数測位の速度・方位・精度・時刻を照合。採用待ちは推定区間として保持 |
| 中 | 高低差の整合判定 | 気圧による相対高度を姿勢・良好なGPS高度と照合。加減速中の端末傾きや気圧急変だけを道路勾配と断定しない |
| 中 | 推定品質の記録・表示 | GPS/慣性/車速/速度保持を区別。欠測時間・入力品質・復帰残差を保存し、未検証の誤差幅を確率保証と呼ばない |
| 後段 | オフライン地図照合 | 高架・地上・地下の階層を持つ地図を候補に使う。平面座標だけで上下の道路へ吸着させず、分岐が曖昧なら複数候補を残す |

推奨順は「原記録 → 停車/姿勢補正 → 復帰判定」です。同じ入力で改良前後を比較できます。現行の走行CSVには25HzのIMU原波形がないため、新しい慣性アルゴリズムの正確な再適用には追加記録が必要です。

## 追加の車速情報

長い欠測の距離安定には、車輪回転センサまたは取得可能なコントローラー車速が有力です。校正したタイヤ外周×回転数で距離を求めれば、加速度の積分だけに依存しません。方位にはジャイロが必要で、空転・外周誤差は別に扱います。

Bluetooth Cycling Speed and Cadence対応の車輪センサ等が接続候補ですが、D4への装着可否・ホイール寸法・コントローラーの通信仕様は未確認です。現在のJBD 03/04読取は車速を取得していません。購入機種や配線はまだ指定しません。

カメラによる移動推定は後段候補です。前方の視界、暗所での追跡、固定角度、発熱・電力の検証が必要です。現在のセンサ機能のためにカメラ権限を増やす必要はありません。

## 現行機能との区別

- 取得済み: GPS、加速度/線形加速度、ジャイロ、通常の回転ベクトル、気圧。搭載有無を起動時に確認。
- 既存のバイアス補正はGPSで静止を確認できる間のみ。GPS欠測中の新たな停車を確実に判別する機能は未実装。
- 60秒を超える欠測では、取得は続いても現行の慣性積分は停止して速度保持へ移行する。
- 通信圏外とGPS未測位を区別する。衛星測位があるなら、携帯通信の欠測だけで慣性推定へ切り替えない。
- 端末は常時固定する前提。固定ON/OFFを再導入しない。
